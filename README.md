# TruthLens

## Project Title

TruthLens: An Intelligent Multimedia Authenticity Verification Platform

## Problem Statement

AI-generated media enables misinformation through synthetic images, videos, audio, and text. Existing platforms lack a unified mechanism to automatically verify multimedia authenticity before such content spreads.

## Objective

TruthLens aims to develop an intelligent platform capable of detecting AI-generated multimedia and providing authenticity assessments to improve digital trust.

## Key Features

- Image Authenticity Detection
- Video Deepfake Detection
- Audio Voice Clone Detection
- AI-generated Text Detection
- Unified Multimedia Verification Dashboard
